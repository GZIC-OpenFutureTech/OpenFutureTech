## 三、修读攻略

2024级 crabpeelmyshell：
- 24级的授课老师是whx老师。这门课是AI专业的选修课，是大数据的必修课，但是两个专业都是王老师授课，所有课程内容和考试安排都完全相同，因此也适用于大数据专业的同学。whx老师教的很好，而且人也非常nice。只要平时有认真上课或者期末考前认真复习，期末基本都不会有比较大的问题。老师在考试之前也会划重点，也有一些练习题目（见exam目录）。每节课会有雨课堂的扫码签到，课堂上还会随机抽人提问，但是回答不出来也不会怎么样（王老师人真的很好）。
- 实验课是比较有意思的，是平时上课内容的实操，详细内容见lab目录。一般是在实验课之前分组完成，然后实验课当天会需要你们根据该次的实验内容进行demo的展示（例如动态路由测试），每一个同学都需要回答助教的问题/进行对应的demo操作（例如在cisco中进行路由表的查询）。实验结束后需要完成实验报告，一组的同学可以使用相同的实验结果截图，但是每个人必须自己完成自己的实验报告。（实验报告的$\LaTeX$模版已在lab目录给出）。
