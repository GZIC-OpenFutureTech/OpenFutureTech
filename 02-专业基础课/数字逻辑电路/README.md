## 一、课程内容
该门课程如果是靳zp老师授课，那么课程内容涵盖**ebook**文件夹中对应教材的1-10章，以及一些VHDL、Verilog代码的内容，这部分在教材之外，老师有提供ppt。
也就是说，在期末考试中会考一些代码，具体形式主要为代码填空，不需要写整段代码（24级真香）

## 二、考核方式

2024级：平时作业（30%）+小测（20%）+期末考试（50%）我们这一级的考试题量同学们普遍反映比较大，和上一届区别很明显，复习的时候建议还是要着重理解老师上课的知识点和例题。

## 三、修读攻略

2024级 crabpeelmyshell：
- 2024级的授课老师是jzp老师（2025-2026-2学期）。jzp老师上课很有趣，而且个人感觉是最符合国际校区“全英教学”的宣传模式。其教学思想相比于其他老师也都较为前卫，因此有的同学很喜欢他，有的同学很不喜欢他。最出名的段子就是“每天上课之前扫码交300块然后你爱干啥干啥”。
- jzp老师的签到方式也非常有趣，他不会搞雨课堂扫码签到或者点名而是采用小测作为一种签到方式。一个学期内会有5次小测，这5次小测会取4个最高分来作为最终的小测成绩，换句话说，你有一次免死金牌。
- 需要注意的是，老师给的小测和作业答案中存在一些错误，切勿照抄。
