## 一、课程内容
尽管这门课是未院所有同学都要修的课，但还是存在一些差异。相比于大数据大同学，人工智能专业的同学还有一个课程设计作业，内容是一个**算法的应用或改进已有算法**，需要遵循CVPR格式。
其余的期末考试、实验课就是两个专业同学都需要的了。值得一提的是，这门课的分数占比为**出勤30%+实验20%+期末50%**。

## 二、考核方式
- **人工智能专业**：期末考 + 课程设计
- **数据科学与大数据技术专业**：期末考
