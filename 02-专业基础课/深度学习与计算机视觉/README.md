## 三、修读攻略

2024级 crabpeelmyshell：
- 24级的授课老师是hxw老师和cxx老师。这门课采用的是Stanford的[cs231n](https://cs231n.stanford.edu/index.html)，期末考试基本覆盖讲的内容，题型为：选择题+判断题+综合题。老师上课也会强调一些考试重点，考前应该也会划重点。如果你平时没听其实也不用慌张，因为这两位老师上课都会用麦克风，这样在[华园视频](video.jw.scut.edu.cn)的课程回放中就可以比较方便地拿到字幕（[如何提取字幕？](https://github.com/jbykkk/scut-courses-replay-extraction)），然后可以结合LLM或者agent的强大能力来帮助你确定重点，针对性复习。
- 从我们这届开始，会有一些考勤和小测内容（已经整理到exam目录下），很可能的原因是往届大家都不愿意来上课hhh。小测一般在某一节课的最后20min，小测之前的那节课老师应该会提醒下节课有小测。小测的内容非常简单，了解过基础应该就可以应付，但是我们这届因为授课时间稍微紧一点只有两次小测，小测的成绩将算入平时分。
- 实验课其实就是完成一些代码，实验课的质量其实还蛮不错的，可以挑战一下手搓。实验后需要提交对应的实验报告，主要就是一些终端运行命令截图和代码TODO的截图，要求不多，基本自由发挥。
